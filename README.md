# Spieleentwicklungskurs Grundschule (Klasse 3/4, Begabtenförderung)

Konzept für einen Enrichment-Kurs, in dem Kinder Spiele nicht spielen, sondern
bauen — erst analog, dann digital, am Ende ein eigenes Projekt für eine
öffentliche Spielemesse.

| Dokument | Inhalt |
|---|---|
| [`KONZEPT.md`](KONZEPT.md) | Leitidee, didaktischer Rahmen, alle vier Module, Differenzierung, Stolpersteine |
| [`STUNDENPLAN.md`](STUNDENPLAN.md) | 30 Doppelstunden im Überblick + Kurzvariante mit 15 |
| [`MATERIAL.md`](MATERIAL.md) | Baukasten, Werkzeuge, Kosten, Vorlagen zum Ausdrucken |

**Kurzfassung:** 4 Einheiten Spielanalyse → 8 Einheiten analoges Prototyping mit
festem Playtest-Ritual → 10 Einheiten Scratch/Twine/Makey Makey → 8 Einheiten
eigenes Projekt mit Pitch, Projektvertrag, Pflicht-Playtests und Messe.
